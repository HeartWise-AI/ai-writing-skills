# CIHR Project Grant: Mandatory RCT Section Headings

## Section 1: The Need for a Trial

| Heading | Number | Description |
|---------|--------|-------------|
| Condition and burden | 1.1 | Describe the condition to be addressed and its associated burden |
| Research questions, objectives, hypotheses | 1.2 | State research questions, objectives, and hypotheses |
| Why is a trial needed now? | 1.3 | Justify why a trial is needed at this time |
| How would results be used? | 1.4 | Describe how results will inform practice, policy, or future research |

## Section 2: The Proposed Trial

| Heading | Number | Description |
|---------|--------|-------------|
| Proposed trial design | 2.1 | Describe the overall trial design |
| Trial interventions | 2.2 | Detail experimental and control interventions |
| Risks to safety of participants | 2.3 | Identify risks and mitigation strategies |
| Allocation to trial groups | 2.4 | Describe randomization and allocation concealment |
| Methods for protecting against bias | 2.5 | Describe blinding and bias mitigation |
| Recruitment | 2.6 | Describe recruitment strategy and timeline |
| Number of centers | 2.7 | List participating centers |
| Duration of treatment period | 2.8 | State treatment duration (or "not applicable" with justification) |
| Frequency and duration of follow-up | 2.9 | Describe follow-up schedule |
| Expected rates of loss to follow-up | 2.10 | Estimate and justify expected attrition |
| Adherence to allocated management | 2.11 | Describe adherence monitoring and fidelity assessment |
| Primary and secondary outcome measures | 2.12 | Define all endpoints with measurement methods |
| How outcomes will be measured at follow-up | 2.13 | Detail outcome ascertainment procedures |
| Sample size | 2.14 | Provide power calculation and justification |
| Health service research issues | 2.15 | Address cost-effectiveness, resource utilization, or health system impact |
| Proposed analyses | 2.16 | Detail statistical analysis plan |
| Interim analyses | 2.17 | Describe interim analysis plan and stopping rules |
| Planned subgroup analyses | 2.18 | List pre-specified subgroup analyses |
| Pilot work | 2.19 | Summarize relevant pilot or preliminary data |
| Knowledge translation plan | 2.20 | Describe dissemination strategy |
| Limitations and challenges | 2.21 | Address potential limitations, mitigation strategies, and conflicts of interest |

## Section 3: Trial Management

| Heading | Number | Description |
|---------|--------|-------------|
| Day-to-day management | 3.1 | Describe operational management structure |
| Roles of applicants | 3.2 | Define each team member's role and contribution |
| Steering committee / DSMB | 3.3 | Describe governance: steering committee composition, DSMB (or justify absence) |

## Verification Checklist

When auditing, verify:
- All 28 headings are present (or explicitly marked "not applicable" with justification)
- Heading numbering is consistent and sequential
- Subsections (e.g., 2.12.1, 2.12.2) are clearly delineated
- No required headings are merged into other sections without clear identification
- Content under each heading addresses the CIHR description above
